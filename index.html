Vulnerability Solution Cases

Case 1 (Login Test)

Authentication & Input Validation

Reflection: Implementing secure authentication required strictly enforcing input validation and preventing hardcoded credentials. We successfully eliminated credential leakage during the login workflow.
View on GitHub

Case 2 (Data 1)

Encrypted Local Data Storage

Reflection: Sensitive user data stored locally was vulnerable to unauthorized extraction via plain storage. Applying AES encryption ensured data at rest remains strictly confidential.
View on GitHub

Case 3 (Data 2)

Network Payload Protection

Reflection: Insecure network transmission allowed potential interceptors to inspect sensitive API payloads. Implementing TLS pinning and payload encryption ensured secure end-to-end data transfer.
View on GitHub

Case 4 (SQL Injection)

Parameterized Database Queries

Reflection: Unsanitized database queries exposed the local Room database to SQL injection attacks. Replacing raw queries with parameterized Room queries completely mitigated the threat.
View on GitHub

Case 5 (Session Handling)

Access Control & Session Tokens

Reflection: Inadequate session management allowed expired tokens to access restricted endpoints. We integrated automated token refresh mechanisms to maintain strict access control.
View on GitHub

Case 6 (API Security)

Secure Key Management & API Integration

Reflection: Storing API keys inside client code created significant security exposure. We migrated sensitive keys to secure environment configurations and backend proxy services.
View on GitHub
